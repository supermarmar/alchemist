The regression function maps a set of covariates to the conditional expectation of a response given those covariates, and it is the best predictor of the response under squared-error loss and, more generally, under any Bregman loss. Averaging it back over the covariate distribution returns the response's overall mean, which is the property a fitted model is expected to preserve.

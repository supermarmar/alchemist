The universal approximation theorem states that a network with a single hidden layer of sufficient width and a non-polynomial activation can approximate any continuous function on a compact set to any prescribed accuracy. The guarantee covers approximation alone, so it says nothing about how well a network fitted on a finite sample generalises, which regularisation and early stopping have to supply separately.

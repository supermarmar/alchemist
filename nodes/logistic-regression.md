Logistic regression is the generalised linear model for a binary response under the logit link, so each covariate scales the odds of the event by a constant factor per unit and the fitted coefficients read directly as log-odds ratios. It is the classical credit scorecard, whose displayed points are an affine rescaling of the same linear predictor.

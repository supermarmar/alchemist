A test applied to a set of graduated estimates to check that the graduation has actually removed the roughness present in the crude data, typically by examining the pattern of higher order differences across the graduated rates. A smoothness test is judged separately from the tests of fit against a standard table, since a set of rates can be smooth without fitting the data well.

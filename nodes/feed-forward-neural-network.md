A feed-forward neural network composes several layers of neurons, each an affine map followed by a non-linear activation, into a feature extractor whose output feeds a generalised linear model readout. Reparametrising the covariates through learned features generalises the ordinary generalised linear model, which is the single-layer, no-hidden-layer special case.

## Definition

The real numbers are distinguished from the rationals by completeness: every
non-empty set of real numbers that is bounded above has a least upper bound
that is itself a real number, a property the rationals lack, since a bounded
set of rationals can fail to have a rational supremum.

## The expression

$$
S \subseteq \mathbb{R}, \ S \ne \varnothing, \ S \text{ bounded above} \implies \exists\, \sup S \in \mathbb{R}
$$

Here $S$ is a non-empty subset of the real numbers bounded above, and $\sup S$
is its supremum, the least real number no smaller than every element of $S$;
the completeness axiom asserts that this supremum always exists as a real
number.

## Why this node exists

Without a guarantee that a bounded set has a real supremum, a monotone bounded
sequence would have no assured limit within the real numbers. Sequences and
series needs this node next, to build convergence on exactly that guarantee.

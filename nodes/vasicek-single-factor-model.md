A single systematic factor, common to every obligor in a calendar period, links a through-the-cycle default probability to a point-in-time one through a loading parameter measuring how far the estimate swings with the cycle. Averaging the model over the factor recovers the through-the-cycle probability exactly, and stressing the factor to an extreme quantile turns the same expression into a portfolio capital formula.

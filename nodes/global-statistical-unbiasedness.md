A fitting procedure is globally statistically unbiased if the expected value of its prediction, taken over a fresh observation independent of the sample it was fitted on, equals the expected value of that observation's own response. Because the expectation runs over data the fitter has not seen, the property is a statement about the fitting procedure rather than a check any single dataset can run.

The adjustments needed to the four graduation tests when a set of crude estimates is being compared against a set of graduated estimates rather than against a standard table, chiefly a reduction in the degrees of freedom to reflect the parameters the graduation has already fitted. Carrying out this comparison in practice, whether against a standard table or a set of graduated estimates, is the applied exercise the adjusted tests support.

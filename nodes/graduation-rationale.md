The reasons for graduating crude mortality estimates before using them, such as removing sampling noise and producing a smooth set of rates suitable for financial calculations, together with the desirable properties a graduated set should have. Smoothness, adherence to the underlying data and suitability for its intended purpose are the three properties graduation is usually judged against.

An activation function applies a fixed non-linear transformation to each neuron's affine input, and without it a network of any depth would collapse to a single linear map. Common choices include the sigmoid, the hyperbolic tangent and the rectified linear unit, each with its own derivative shape that governs how gradients propagate through it during training.

## Definition

A process is previsible when its value at a given time is measurable with respect to the
information available strictly before that time. This is stricter than being merely adapted,
which only requires measurability with respect to information available up to and including
that time itself; a previsible process is measurable one step earlier.

## The expression

$$
\phi_t \text{ is } \mathcal{F}_{t^-}\text{-measurable}, \qquad
\mathcal{F}_{t^-} = \bigvee_{s \lt t} \mathcal{F}_s
$$

Here $\phi_t$ is the process at time $t$, $\mathcal{F}_{t^-}$ is the sigma-algebra generated by
all information available strictly before $t$, and $\mathcal{F}_s$ is the filtration the
previous node defines at each earlier time $s$. A process satisfying this condition at every $t$
is previsible.

## Why this node exists

A trading strategy that could react to information revealed at the very instant it trades would
be using that instant's own outcome as an input to the same instant's decision, and
previsibility is the condition that rules this out formally. Self-financing portfolio strategy
needs this node next, since a strategy can only be self-financing once its holdings are already
fixed by information available before each price move it trades against.

Principal component analysis finds the linear directions of greatest variance in a set of standardised covariates, each direction orthogonal to and uncorrelated with the ones before it, giving the optimal linear compression of the data at any chosen width. Because the criterion never references a response, a component can align with structure the response does not depend on.

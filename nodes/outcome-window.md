A fixed-horizon outcome window turns a time to default into a binary flag by asking whether default arrives within a chosen number of months of origination, with a loan retained only once that window has fully elapsed. Widening or narrowing the window changes both the measured default rate and the sample retained, so the window and the default definition cannot be chosen independently.

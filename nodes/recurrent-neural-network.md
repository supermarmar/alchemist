A recurrent layer carries a hidden state forward through a sequence, updating it at each step from the current input and the state's own previous value, so the state at any point summarises everything seen up to it. Long short-term memory and the gated recurrent unit add gates that let information from far back in the sequence still reach a later prediction, which plain recurrence struggles to do.
